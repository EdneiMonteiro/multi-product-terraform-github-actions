# Suporte

## Como obter ajuda

Este projeto utiliza GitHub Issues para:

- bugs;
- dúvidas;
- sugestões;
- melhorias na documentação.

Antes de abrir uma issue:

1. Verifique se já existe uma semelhante.
2. Leia o [README](./README.md).
3. Leia o [DISCLAIMER](./DISCLAIMER.md).

## O que incluir

- Descrição clara.
- Passos para reproduzir.
- Resultado esperado versus resultado ocorrido.
- Logs ou prints.
- Versões utilizadas.
- Link do workflow run, quando aplicável.

## Nível de suporte

Este projeto:

- não possui SLA;
- não garante resposta;
- não garante correções;
- não garante evolução;
- não substitui suporte oficial de fornecedores.

## Suporte oficial

Este repositório **não substitui suporte oficial da Microsoft, GitHub, HashiCorp ou Azure**.

Para ambientes produtivos, utilize os canais oficiais de suporte.
